NIXOS + MANGO PERSONAL COMMAND GUIDE
For this laptop:
  User: aesc
  Flake output: tonelico
  Main NixOS folder: /etc/nixos
  GitHub backup folder: ~/nixos-config

============================================================
1. OPEN AND EDIT YOUR CONFIG FILES
============================================================

Main NixOS settings:
  sudo nano /etc/nixos/configuration.nix

Apps, Steam, Prism, Lotus, Chromium, cursor:
  sudo nano /etc/nixos/apps-and-lotus.nix

Flake inputs and imported modules:
  sudo nano /etc/nixos/flake.nix

Machine mounts, UUIDs, and hardware modules:
  sudo nano /etc/nixos/hardware-configuration.nix

IMPORTANT:
Normally do not edit hardware-configuration.nix by hand.
Generate a fresh one after reinstalling or changing partitions.

Mango window manager:
  nano ~/.config/mango/config.conf

Noctalia shell:
  nano ~/.config/noctalia/config.toml

Kitty terminal:
  nano ~/.config/kitty/kitty.conf

Fcitx5:
  fcitx5-configtool

View all NixOS config files:
  ls -lah /etc/nixos

View your backed-up Git repository:
  ls -lah ~/nixos-config

Nano controls:
  Save: Ctrl+O, Enter
  Exit: Ctrl+X
  Search: Ctrl+W


============================================================
2. APPLY CONFIG CHANGES
============================================================

Check/build without activating:
  sudo nixos-rebuild build --flake /etc/nixos#tonelico

Apply immediately and add a boot generation:
  sudo nixos-rebuild switch --flake /etc/nixos#tonelico

Build for the next boot without changing the running system:
  sudo nixos-rebuild boot --flake /etc/nixos#tonelico

Test temporarily without adding a boot generation:
  sudo nixos-rebuild test --flake /etc/nixos#tonelico

Reload Mango after editing its config:
  mango -c ~/.config/mango/config.conf -p
  mmsg dispatch reload_config

Restart Noctalia if its panel becomes stuck:
  pkill -x noctalia
  sleep 1
  noctalia --daemon


============================================================
3. INSTALL OR REMOVE APPLICATIONS
============================================================

Search for a package:
  nix search nixpkgs PACKAGE_NAME

Open your app list:
  sudo nano /etc/nixos/apps-and-lotus.nix

Add the package inside:
  environment.systemPackages = with pkgs; [
    package-name
  ];

Apply:
  sudo nixos-rebuild switch --flake /etc/nixos#tonelico

Remove an app:
  Delete its package line, save, then rebuild again.

Temporarily run an app without permanently installing it:
  nix shell nixpkgs#PACKAGE_NAME -c COMMAND_NAME

3A. LAZYVIM INSTALLATION AND USE
============================================================

LazyVim is your Neovim configuration. The NixOS package list should provide:
  neovim
  git
  lazygit
  tree-sitter
  gcc
  curl
  fzf
  ripgrep
  fd

Install LazyVim automatically with the supplied helper:
  chmod +x ~/Downloads/install-lazyvim-and-backup.sh
  ~/Downloads/install-lazyvim-and-backup.sh

Open LazyVim:
  nvim

Open a file:
  nvim FILE_NAME

Open the current directory:
  nvim .

Run LazyVim's health check from inside Neovim:
  :LazyHealth

Useful LazyVim controls:
  Space              Leader key / command menu
  Space, f, f        Find files
  Space, s, g        Search text with grep
  Space, e           File explorer
  Space, g, g        Lazygit
  :q                 Close the current view
  :qa                Close Neovim
  :w                 Save
  :wq                Save and quit

LazyVim files:
  ~/.config/nvim

LazyVim plugin data and cache:
  ~/.local/share/nvim
  ~/.local/state/nvim
  ~/.cache/nvim

Back up the LazyVim configuration to GitHub:
  Copy ~/.config/nvim into:
  ~/nixos-config/dotfiles/.config/nvim

Do not upload ~/.local/share/nvim or ~/.cache/nvim.
They contain downloaded/generated data that LazyVim can recreate.

============================================================
4. UPDATE NIXOS, APPS, MANGO, NOCTALIA, AND LOTUS
============================================================

Update all flake inputs and apply:
  cd /etc/nixos
  sudo nix flake update
  sudo nixos-rebuild switch --flake /etc/nixos#tonelico

Recommended safer update:
  cd /etc/nixos
  sudo cp flake.lock flake.lock.before-update
  sudo nix flake update
  sudo nixos-rebuild build --flake /etc/nixos#tonelico
  sudo nixos-rebuild switch --flake /etc/nixos#tonelico

After a kernel or firmware update:
  reboot

See what inputs are locked:
  nix flake metadata /etc/nixos


============================================================
5. ROLLBACK AND RECOVERY
============================================================

Return to the previous system generation:
  sudo nixos-rebuild switch --rollback

List generations:
  sudo nixos-rebuild list-generations

At startup:
  Open the systemd-boot menu and select an older NixOS generation.

Check failed services:
  systemctl --failed

Show serious errors from the current boot:
  journalctl -b -p err..alert

Show the previous boot:
  journalctl -b -1

Restore the flake lock saved before an update:
  cd /etc/nixos
  sudo cp flake.lock.before-update flake.lock
  sudo nixos-rebuild switch --flake /etc/nixos#tonelico


============================================================
6. KEEP ONLY FIVE NIXOS GENERATIONS
============================================================

ONE-TIME: make the boot menu keep at most five NixOS entries.

Your starter originally used:
  configurationLimit = 2;

Change it to 5 automatically:
  sudo sed -i -E \
    's/configurationLimit = [0-9]+;/configurationLimit = 5;/' \
    /etc/nixos/configuration.nix

Confirm:
  grep -n 'configurationLimit' /etc/nixos/configuration.nix

Apply:
  sudo nixos-rebuild switch --flake /etc/nixos#tonelico

After confirming the current system works, keep the latest five
system-profile generations:
  sudo nix-env \
    --profile /nix/var/nix/profiles/system \
    --delete-generations +5

Free store paths that no remaining generation uses:
  sudo nix-store --gc

Check what remains:
  sudo nixos-rebuild list-generations

IMPORTANT:
Run generation deletion only after confirming the newest system works.
Keeping five boot entries and five system generations gives you recovery
choices without keeping unlimited old versions.


============================================================
7. UPLOAD YOUR CURRENT WORKING CONFIG TO GITHUB
============================================================

Use this only after a rebuild/update works correctly.

First enter the local repository:
  cd ~/nixos-config

Download remote changes without applying them:
  git fetch

Download and apply remote changes:
  git pull --rebase

Copy the current NixOS files:
  sudo cp -a \
    /etc/nixos/flake.nix \
    /etc/nixos/flake.lock \
    /etc/nixos/configuration.nix \
    /etc/nixos/hardware-configuration.nix \
    /etc/nixos/apps-and-lotus.nix \
    ~/nixos-config/

Return ownership to your user:
  sudo chown -R "$USER":"$(id -gn)" ~/nixos-config

Refresh your desktop dotfiles:
  rm -rf ~/nixos-config/dotfiles/.config/{mango,kitty,noctalia,fcitx5,nvim}
  mkdir -p ~/nixos-config/dotfiles/.config

  for APP in mango kitty noctalia fcitx5 nvim; do
    if [ -d "$HOME/.config/$APP" ]; then
      cp -a "$HOME/.config/$APP" \
        ~/nixos-config/dotfiles/.config/
    fi
  done

Optionally save your default-app associations:
  if [ -f "$HOME/.config/mimeapps.list" ]; then
    cp -a "$HOME/.config/mimeapps.list" \
      ~/nixos-config/dotfiles/.config/
  fi

Review changes:
  cd ~/nixos-config
  git status
  git diff

Commit and upload:
  git add -A
  git status --short

  if git diff --cached --quiet; then
    echo "No new configuration changes to upload."
  else
    git commit -m "Working NixOS config $(date +%F-%H%M)"
    git push
  fi

Open the repository in your browser:
  gh repo view --web

Show the exact GitHub destination:
  git remote -v

IMPORTANT:
git push uploads only committed files inside ~/nixos-config.
It does not automatically copy changes from /etc/nixos or ~/.config.


============================================================
8. RESTORE EVERYTHING AFTER A MINIMAL NO-DESKTOP REINSTALL
============================================================

Use this after installing and booting a basic/minimal NixOS system.

A. Log in at the text console and get temporary Git tools:

  nix-shell -p git gh

B. Sign in to GitHub:

  gh auth login --hostname github.com --git-protocol https --web

Follow the device-code/browser instructions.

C. Clone your private repository:

  rm -rf /tmp/nixos-config
  gh repo clone nixos-config /tmp/nixos-config

The owner can be omitted because GitHub CLI uses the authenticated account.

D. ALWAYS KEEP THE NEW INSTALL'S HARDWARE FILE.

Use the newly generated hardware-configuration.nix from the new installation.
Do not replace it with the copy from GitHub, even on the same laptop.

Why:
  - A new partition or format normally creates new filesystem UUIDs.
  - The detected initrd modules and filesystems belong to the new install.
  - The old GitHub copy is useful only as a reference.

The safest rule is:
  Restore every saved config file EXCEPT hardware-configuration.nix.
  Keep the fresh hardware-configuration.nix generated by the installer.

Save the fresh hardware file before copying the rest of the repository:

  sudo cp \
    /etc/nixos/hardware-configuration.nix \
    /tmp/hardware-configuration.new.nix

E. Copy your saved configuration:

  sudo cp -a \
    /tmp/nixos-config/flake.nix \
    /tmp/nixos-config/flake.lock \
    /tmp/nixos-config/configuration.nix \
    /tmp/nixos-config/apps-and-lotus.nix \
    /etc/nixos/

Restore the newly generated hardware file:
  sudo cp \
    /tmp/hardware-configuration.new.nix \
    /etc/nixos/hardware-configuration.nix

F. Build your complete Mango + Noctalia desktop:

  sudo nixos-rebuild switch \
    --flake /etc/nixos#tonelico \
    --option experimental-features "nix-command flakes"

This configuration should recreate:
  Mango
  Noctalia
  Noctalia Greeter
  Chromium
  Kitty
  Steam
  Prism Launcher
  OBS
  Discord
  Obsidian
  Lotus
  LazyVim (after restoring ~/.config/nvim)
  your declared drivers and services

G. Put the Git repository and dotfiles into aesc's home:

  sudo rm -rf /home/aesc/nixos-config
  sudo cp -a /tmp/nixos-config /home/aesc/nixos-config

  sudo mkdir -p /home/aesc/.config
  sudo cp -a \
    /tmp/nixos-config/dotfiles/.config/. \
    /home/aesc/.config/

  sudo chown -R \
    aesc:"$(id -gn aesc)" \
    /home/aesc/nixos-config \
    /home/aesc/.config

H. Reboot:

  sudo reboot

At Noctalia Greeter, choose Mango if needed and log in as aesc.

IMPORTANT REINSTALL NOTES:
  1. Always keep the newly generated hardware-configuration.nix; never overwrite it with the GitHub copy.
  2. Do not blindly restore old disk UUIDs after repartitioning.
  3. Keep system.stateVersion at the value already saved in your config.
  4. This repository restores declared programs and selected settings.
  5. It does not restore personal documents, browser profiles, games,
     passwords, Secret Service contents, or files that were never committed.
