NIXOS + MANGO COMMAND / BACKUP / REINSTALL GUIDE — V5
AESC / TONELICO
======================================================================

PURPOSE
  This file is the "copy first, explain second" guide for this NixOS setup.
  Most sections include:
    1) a short command for when you already know what you want;
    2) a whole copy-paste script/block that does the safer version.

CURRENT LAYOUT
  User:                 aesc
  Current flake output: tonelico
  NixOS config:         /etc/nixos
  GitHub working copy:  ~/nixos-config
  Mango config:         ~/.config/mango/config.conf
  Noctalia config:      ~/.config/noctalia
  LazyVim config:       ~/.config/nvim

IMPORTANT HARDWARE RULE
  NEVER copy an old hardware-configuration.nix onto another PC.
  NEVER upload hardware-configuration.nix to GitHub.

  On a new PC:
    - install NixOS fresh;
    - keep THAT PC's newly generated /etc/nixos/hardware-configuration.nix;
    - restore the reusable configuration around it.

  hardware-configuration.nix is not the only possible machine-specific
  configuration. CPU/GPU driver settings can also be machine-specific.
  This Tonelico configuration has historically contained Intel-specific
  graphics/microcode settings. On AMD or NVIDIA hardware, review those
  settings before switching to the restored configuration.

  (
  set -euo pipefail

  echo "=== Build first ==="

======================================================================
2. FULL SYSTEM UPDATE
======================================================================

QUICK COMMANDS
  cd /etc/nixos
  sudo nix flake update
  sudo nixos-rebuild build --flake .#tonelico
  sudo nixos-rebuild switch --flake .#tonelico

FULL COPY-PASTE BLOCK
  (
  set -euo pipefail

  cd /etc/nixos

  STAMP="$(date +%F-%H%M%S)"

  if [ -f flake.lock ]; then
    sudo cp -a flake.lock "flake.lock.before-update-$STAMP"
  fi

  echo "=== Update all flake inputs ==="
  sudo nix flake update

  echo "=== Build before activation ==="
  sudo nixos-rebuild build --flake .#tonelico

  echo "=== Activate ==="
  sudo nixos-rebuild switch --flake .#tonelico

  echo "=== Flatpak ==="
  if command -v flatpak >/dev/null 2>&1; then
    flatpak update -y || true
  fi

  echo "=== LazyVim plugins ==="
  if command -v nvim >/dev/null 2>&1 &&
     [ -d "$HOME/.config/nvim" ]; then
    timeout 300 nvim --headless "+Lazy! sync" +qa || true
  fi

  echo "=== Firmware metadata ==="
  if command -v fwupdmgr >/dev/null 2>&1; then
    sudo fwupdmgr refresh --force || true
    sudo fwupdmgr get-updates || true
  fi

  echo
  echo "UPDATE COMPLETE"
  echo "Reboot if the update changed the kernel, graphics stack,"
  echo "firmware, bootloader, or greeter."
  )

INSTALL AVAILABLE FIRMWARE UPDATE
  sudo fwupdmgr update

REBOOT
  sudo reboot

5. HEALTH CHECK AFTER A REBUILD
======================================================================

COPY THIS WHOLE BLOCK
  (
  set +e

  echo
  echo "===== CURRENT SYSTEM ====="
  readlink -f /run/current-system
  uname -a

  echo
  echo "===== FAILED SYSTEM SERVICES ====="
  systemctl --failed --no-legend --plain
  [ "$?" -eq 0 ] && echo "No failed system services."

  echo
  echo "===== FAILED USER SERVICES ====="
  systemctl --user --failed --no-legend --plain
  [ "$?" -eq 0 ] && echo "No failed user services."

  echo
  echo "===== MANGO ====="
  if mango -c "$HOME/.config/mango/config.conf" -p; then
    echo "Mango config: OK"
  else
    echo "Mango config: FAILED"
  fi

  echo
  echo "===== NOCTALIA ====="
  noctalia msg status || echo "Noctalia did not respond."

  echo
  echo "===== AUDIO ====="
  wpctl get-volume @DEFAULT_AUDIO_SINK@ ||
    echo "No default audio sink."

  echo
  echo "===== NETWORK ====="
  nmcli -t -f DEVICE,TYPE,STATE device status || true

  echo
  echo "===== GREETER ====="
  printf "greetd: "
  systemctl is-enabled greetd.service 2>/dev/null || true
  printf "sddm:   "
  systemctl is-enabled sddm.service 2>/dev/null || true

  echo
  echo "===== IMPORTANT COMMANDS ====="
  for cmd in chromium kitty obs prismlauncher steam nvim \
             fetch noctalia mango wpctl; do
    if command -v "$cmd" >/dev/null 2>&1; then
      printf "OK      %-18s %s\n" "$cmd" "$(command -v "$cmd")"
    else
      printf "MISSING %-18s\n" "$cmd"
    fi
  done

  echo
  echo "===== ROOT DISK ====="
  df -h /

  echo
  echo "===== GENERATIONS ====="
  sudo nixos-rebuild list-generations | tail -n 10
  )

MANUAL CHECKS
  [ ] Chromium opens
  [ ] Kitty opens
  [ ] Super+Space launcher works
  [ ] Noctalia bar works
  [ ] Super+Shift+Alt+R toggles Bread/DWM <-> Original
  [ ] audio and volume keys work
  [ ] Wi-Fi/Bluetooth work
  [ ] screenshots go to ~/Pictures/Screenshots
  [ ] OBS records into ~/Videos/OBS
  [ ] nvim opens LazyVim
  [ ] Steam starts the way you expect
  [ ] reboot once after major system changes

6. ROLLBACK / RECOVERY
======================================================================

QUICK ROLLBACK
  sudo nixos-rebuild switch --rollback

COPY-PASTE RECOVERY BLOCK
  (
  set -e

  echo "Recent generations:"
  sudo nixos-rebuild list-generations | tail -n 12

  echo
  echo "Switching to the previous generation..."
  sudo nixos-rebuild switch --rollback

  echo
  echo "Current generation:"
  readlink -f /run/current-system
  )

IF THE MACHINE CANNOT BOOT
  In systemd-boot, select an older NixOS generation.

RESTORE THE LAST SAVED FLAKE LOCK
  (
  set -euo pipefail
  cd /etc/nixos

  OLD="$(ls -1t flake.lock.before-update-* 2>/dev/null | head -n1)"

  if [ -z "$OLD" ]; then
    echo "No saved flake.lock backup found."
    exit 1
  fi

  echo "Restoring: $OLD"
  sudo cp -a "$OLD" flake.lock
  sudo nixos-rebuild build --flake .#tonelico
  sudo nixos-rebuild switch --flake .#tonelico
  )

15. RESTORE ONLY USER CONFIG / DOTFILES FROM GITHUB
======================================================================

This does NOT touch /etc/nixos.

COPY-PASTE
  (
  set -euo pipefail

  REPO="$HOME/nixos-config"

  test -d "$REPO/.git" || {
    echo "Missing $REPO"
    exit 1
  }

  cd "$REPO"
  git pull --rebase --autostash

  if [ -d "$REPO/dotfiles/.config" ]; then
    cp -a "$REPO/dotfiles/.config/." "$HOME/.config/"
  fi

  if [ -d "$REPO/dotfiles/.local/bin" ]; then
    mkdir -p "$HOME/.local/bin"
    cp -a "$REPO/dotfiles/.local/bin/." "$HOME/.local/bin/"
    chmod +x "$HOME/.local/bin/"* 2>/dev/null || true
  fi

  if [ -d "$REPO/dotfiles/.local/share/applications" ]; then
    mkdir -p "$HOME/.local/share/applications"
    cp -a "$REPO/dotfiles/.local/share/applications/." \
      "$HOME/.local/share/applications/"
  fi


  # DESKTOP_LOOK_PROFILE_RESTORE
  if [ -d "$REPO/dotfiles/.local/share/desktop-look-toggle" ]; then
    mkdir -p "$HOME/.local/share"

    rm -rf "$HOME/.local/share/desktop-look-toggle"

    cp -a \
      "$REPO/dotfiles/.local/share/desktop-look-toggle" \
      "$HOME/.local/share/desktop-look-toggle"

    mkdir -p "$HOME/.local/state/noctalia"

    # A clean restore starts in Bread/DWM.
    cp -a \
      "$HOME/.local/share/desktop-look-toggle/dwm/mango.conf" \
      "$HOME/.config/mango/config.conf"

    cp -a \
      "$HOME/.local/share/desktop-look-toggle/dwm/noctalia-settings.toml" \
      "$HOME/.local/state/noctalia/settings.toml"

    printf '%s\n' dwm \
      > "$HOME/.local/share/desktop-look-toggle/active"

    if [ -f "$HOME/.local/bin/toggle-desktop-look" ]; then
      chmod +x "$HOME/.local/bin/toggle-desktop-look"
    fi
  fi
  echo "Dotfiles restored."
  echo "Log out/in if launcher entries or PATH changes do not appear."
  )

16. NEW DEVICE: FRESH NIXOS INSTALL + SAFE RESTORE WITHOUT MIXING HARDWARE
======================================================================

THIS SECTION IS THE ONLY NEW-PC INSTALL SECTION.
Use it whenever you move this setup to another machine.

----------------------------------------------------------------------
A. WHAT MUST BE DIFFERENT ON EACH PC
----------------------------------------------------------------------

DO NOT copy from the old PC:
  /etc/nixos/hardware-configuration.nix

The new machine must keep the hardware-configuration.nix created for
that machine.

Also review CPU/GPU-specific settings. The Tonelico setup was made on
an Intel laptop and has historically used settings such as:
  hardware.cpu.intel.updateMicrocode
  intel-media-driver
  vpl-gpu-rt
  intel-compute-runtime
  LIBVA_DRIVER_NAME = "iHD"
  modesetting

A different Intel PC may still work with some of these.
AMD or NVIDIA hardware needs its own appropriate graphics/CPU settings.

----------------------------------------------------------------------
B. FRESH INSTALL
----------------------------------------------------------------------

Recommended safest route:
  1. Boot an official NixOS x86_64 installer USB.
  2. Install NixOS fresh onto the NEW PC.
  3. Do NOT clone the old disk.
  4. Do NOT bring over the old hardware-configuration.nix.
  5. A minimal/no-desktop install is fine.
  6. Boot the new NixOS installation.
  7. Make sure networking works.
  8. Run the restore script in part C.

If you manually install with the minimal ISO, generate the new hardware
configuration only AFTER the new root/boot filesystems are mounted:
  sudo nixos-generate-config --root /mnt

That generated file belongs to the new computer.

----------------------------------------------------------------------
C. ONE RESTORE SCRIPT AFTER THE FRESH INSTALL
----------------------------------------------------------------------

Put restore-nixos-new-device.sh in ~/Downloads, then run:

  chmod +x ~/Downloads/restore-nixos-new-device.sh
  ~/Downloads/restore-nixos-new-device.sh

The script:
  - refuses to continue if the fresh hardware-configuration.nix is missing;
  - makes a separate backup of the new hardware file;
  - clones or updates your GitHub repository;
  - restores the reusable NixOS config;
  - puts the NEW machine's hardware-configuration.nix back;
  - restores your Mango/Noctalia/Kitty/LazyVim/etc. dotfiles;
  - shows CPU and GPU information;
  - searches restored Nix files for Intel/AMD/NVIDIA-specific settings;
  - builds first;
  - requires explicit confirmation before switch.

For a new device, BUILD FIRST. Do not automatically switch a config
that has not successfully built.

----------------------------------------------------------------------
D. AFTER THE RESTORE SCRIPT BUILDS SUCCESSFULLY
----------------------------------------------------------------------

Check the hardware information it printed.

If the new PC is another Intel x86_64 machine with Intel graphics:
  the restored config is likely close to what you need.

If the new PC has an AMD CPU/GPU or NVIDIA GPU:
  adjust the machine-specific CPU/GPU settings before typing SWITCH.

Then activate:
  sudo nixos-rebuild switch --flake /etc/nixos#tonelico

Reboot:
  sudo reboot

After reboot, verify:
  [ ] boot works
  [ ] Mango session starts
  [ ] Noctalia starts
  [ ] display resolution/refresh rate is correct
  [ ] Wi-Fi works
  [ ] Bluetooth works
  [ ] laptop/PC audio works
  [ ] brightness keys work if the machine has them
  [ ] suspend/resume works
  [ ] Steam/Prism/OBS/Chromium start
  [ ] external monitor works

----------------------------------------------------------------------
E. IF THE NEW MACHINE HAS DIFFERENT GRAPHICS
----------------------------------------------------------------------

DO NOT solve this by copying the old hardware-configuration.nix.

Keep the new hardware-configuration.nix and change the reusable
CPU/GPU driver configuration instead.

Useful search:
  grep -RniE \
    'intel|nvidia|amdgpu|iHD|modesetting|videoDrivers|updateMicrocode' \
    /etc/nixos \
    --include='*.nix'

This shows the settings that deserve review.

----------------------------------------------------------------------
F. HOSTNAME / FLAKE NAME
----------------------------------------------------------------------

The restored system currently uses the flake output:
  tonelico

It may also set:
  networking.hostName = "tonelico";

You can keep that name, or change it for the new PC. If you later
create separate flake outputs per machine, each PC can have its own
host entry while sharing the same common desktop configuration.

RECOMMENDED LONG-TERM REPOSITORY IDEA
  common/
    desktop.nix
    apps.nix

  hosts/
    tonelico/
      default.nix
      hardware-configuration.nix   <-- local only / gitignored
    new-pc/
      default.nix
      hardware-configuration.nix   <-- local only / gitignored

The important principle stays the same:
  shared desktop/apps = reusable
  hardware file + machine drivers = per-device

18. ORIGINAL <-> BREAD/DWM DESKTOP LOOK SWITCHER
======================================================================

CURRENT BEHAVIOR

  This setup has two independently editable appearance profiles:

    Bread / DWM
    Original

  Mango and Noctalia switch together.

  Before the other profile is loaded, the currently active Mango config
  and Noctalia settings are saved back into the active profile. Changes
  made to either appearance therefore persist independently.


KEYBIND

  Super + Shift + Alt + R


MANUAL COMMANDS

  toggle-desktop-look
  toggle-desktop-look dwm
  toggle-desktop-look original
  toggle-desktop-look save
  toggle-desktop-look status


AUTHORITATIVE FILES

  Switcher:
    ~/.local/bin/toggle-desktop-look

  Shared Mango keybind:
    ~/.config/mango/look-toggle.conf

  Bread/DWM:
    ~/.local/share/desktop-look-toggle/dwm/mango.conf
    ~/.local/share/desktop-look-toggle/dwm/noctalia-settings.toml

  Original:
    ~/.local/share/desktop-look-toggle/original/mango.conf
    ~/.local/share/desktop-look-toggle/original/noctalia-settings.toml


BACKUP / UPDATE SCRIPT

  Full system update + health check + GitHub snapshot:

    ~/Downloads/update-system-and-push-v3.1.sh

  GitHub snapshot only, without updating NixOS:

    ~/Downloads/update-system-and-push-v3.1.sh --sync-only


MANGO RELOAD

  Correct:
    mmsg dispatch reload_config

  Obsolete / incorrect:
    mmsg -d reload_config


IMPORTANT

  Do not manually recreate gap, opacity, blur, border, animation, bar or
  panel values from this guide. The Mango and Noctalia profile files are
  the authoritative current values.

  The abandoned Noctalia authentication-logo/custom-assets experiment is
  not part of the reproducible configuration and must not add
  NOCTALIA_ASSETS_DIR to the restored setup.
